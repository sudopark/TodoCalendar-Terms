# To-do Calendar

**你的待办和日程，都在同一个日历上。**

日历能装下约会，却装不下你要做完的事。待办应用给你一份清单，却看不出这些事落在这个月的哪一天。To-do Calendar 把两者放进同一个日历：日程落在它发生的那天，待办则一直摆在你眼前，直到你真的把它勾掉 —— 哪怕它没有设定时间。

不联网、不注册账户也能完整使用。只有当你想备份数据、在多台设备间同步时才需要登录。

- **一个日历，两种事情** —— 日程和待办并排显示，用你自己创建的事件类型颜色区分
- **不会消失的待办** —— 没有时间的待办和过期未完成的待办钉在最上方，不会被留在过去的日期上
- **说一句就能添加** —— 用AI快捷输入、Siri 或操作按钮，用日常语言描述一件事
- **不打开应用也能看见这一天** —— 覆盖主屏幕、锁定屏幕和控制中心的丰富小组件
- **把原来的日历带过来** —— 连接 Google日历和 Apple日历，所有安排在一处查看

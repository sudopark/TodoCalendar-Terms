# To-do Calendar

**您的待辦事項與行程，同在一個行事曆上。**

大多數行事曆只放得下約會，而大多數待辦事項應用程式沒有「一個月」的概念。To-do Calendar 把兩者放在同一個格線上：行程落在它發生的那一天，待辦事項則會一直留在您眼前，直到您真的把它勾掉——就算沒有指定時間也一樣。

不需要網路、也不需要帳號，就能完整使用。只有在想備份資料、想在多台裝置間同步時，才需要登入。

- **一個行事曆，兩種事情** — 行程與待辦事項並排呈現，以您自訂的活動類型色彩區分
- **不會消失的待辦事項** — 沒有時間的待辦事項與逾期的待辦事項會留在最上方，不會被捲進過去
- **用說的就能新增** — 透過 AI 快速輸入、Siri 或操作按鈕，用日常語言描述活動
- **不用打開也看得到** — 涵蓋主畫面、鎖定畫面與控制中心的完整小工具組
- **把原本的行事曆帶過來** — 連接 Google 日曆與 Apple 日曆，所有活動一目了然

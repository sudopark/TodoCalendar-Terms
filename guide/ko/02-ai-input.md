# 2. AI 빠른 입력

[← 목차](./README.md)

---

원하는 걸 일상 언어로 말하면 앱이 만들어줘요 — "금요일 12시에 사라랑 점심", "치과 다음 주 화요일로 옮겨줘", "빨래 완료 처리해줘". 양식도, 날짜 휠도 필요 없어요.

<img src="https://raw.githubusercontent.com/sudopark/TodoCalendar-Terms/main/guide/images/ko/ai-input.png" alt="AI 빠른 입력" width="280">

AI 빠른 입력은 로그인이 필요해요. 그 외 기능은 계정 없이도 전부 쓸 수 있어요.

---

## 할 수 있는 일

- 할일과 일정 만들기 — 말한 내용에서 시간·반복·이벤트 종류를 알아서 잡아줘요
- 기존 이벤트 바꾸기 — 시간 옮기기, 이름 바꾸기, 시간대 조정
- 할일 완료 처리하기, 완료 취소하기
- 이벤트 삭제하기
- 한 번에 여러 개 처리하기 ("월수금 아침 7시에 운동 추가해줘")

---

## 요청을 보내는 방법

### 앱에서

캘린더 화면의 AI 버튼을 누르면 입력 시트가 열려요. 두 가지 모드를 언제든 오갈 수 있어요.

- **음성** — 말하면 인식된 내용이 실시간으로 보여요. 마이크와 음성 인식 권한이 필요하고, 거부돼 있으면 설정으로 이동하거나 **키보드로 입력**하도록 안내해요.
- **키보드** — 직접 타이핑해요. 말하기 곤란한 곳에서 유용해요.

### 이미지에서

**이미지에서 읽기**는 사진을 이벤트로 바꿔줘요. **사진 촬영**하거나 **라이브러리에서 선택**하면 앱이 이미지 속 글자를 읽어요 — 수업 시간표, 행사 포스터, 대화 캡처 같은 것들요. 읽어낸 텍스트를 먼저 보여주니 어색한 부분은 보내기 전에 고칠 수 있어요.

"이걸 할 일로 추가해줘" 같은 **추가 지시(선택)**를 붙여 결과를 조정할 수도 있어요. 이미지에서 읽을 글자가 없으면 빈 요청을 보내는 대신 그렇다고 알려줘요.

### Siri

**"To-do Calendar에 AI로 추가"**라고 말하세요 — "To-do Calendar에 일정 추가", "To-do Calendar에 할일 추가"도 돼요. Siri가 무엇을 추가할지 묻고, 요청은 **앱을 열지 않고 백그라운드에서** 처리돼요. Siri가 "알겠어요. 끝나면 알려드릴게요"라고 답하고, 결과가 준비되면 알림이 와요.

### 액션 버튼

액션 버튼에 **AI로 추가** 단축어를 지정해두세요. 한 번 누르고 말하면 끝이고, 앱이 앞으로 나올 일도 없어요.

### 위젯과 제어 센터

- **AI로 추가 위젯** — 홈 화면이나 잠금화면에서 한 번 탭하면 AI 입력 화면이 열려요.
- **제어 센터** (iOS 18 이상) — 같은 컨트롤을 제어 센터에 추가해두면 어디서든 쓸어내려 바로 들어갈 수 있어요.

### 공유 시트

다른 앱의 **텍스트나 이미지를 그대로 AI로 보낼 수 있어요**. 약속 정보가 담긴 메시지를 읽는 중이거나 사진 앱에서 포스터를 보고 있다면, 공유를 눌러 To-do Calendar를 고르고 필요하면 지시를 덧붙여 보내세요.

공유 시트 요청도 백그라운드로 처리돼요. 보냈다는 확인만 뜨고, 결과는 앱에서 확인하면 돼요.

---

## 요청이 처리되는 과정

1. **전송** — 요청이 떠나요. Siri·액션 버튼·공유 시트에서 보냈다면 앱을 켜두지 않아도 돼요.
2. **처리 중** — 진행 상태가 보여요. 진행 중에 **중지**할 수 있는데, 중지하면 진행 중이던 작업이 사라지고 다시 시작할 수 없어요.
3. **확인 필요** — 중요한 변경이 될 요청이면 앱이 무엇을 하려는지 보여주고 먼저 승인을 받아요. 제한 시간이 있고, 지나면 다시 요청하면 돼요.
4. **작업 완료** — 결과가 곧바로 캘린더에 반영되고, 무엇이 바뀌었는지 요약해서 알려줘요.

<img src="https://raw.githubusercontent.com/sudopark/TodoCalendar-Terms/main/guide/images/ko/ai-result.png" alt="AI 처리 결과" width="280">

한 번에 하나의 요청만 처리돼요. 승인을 기다리는 요청이 있는 상태에서 또 보내면, 앞선 요청을 먼저 처리해 달라고 안내해요.

---

## 크레딧

AI 요청은 **매일 초기화되는 하루치 크레딧**을 사용해요. 남은 양은 AI 입력 화면 위쪽에 항상 표시되니, 보내기 전에 얼마나 남았는지 알 수 있어요.

크레딧을 다 쓰면 다음 초기화까지 AI 빠른 입력이 쉬어가요. 나머지 기능은 그대로 쓸 수 있어요.

---

## 요청할 수 있는 권한

| 권한 | 쓰이는 곳 |
|---|---|
| 마이크 + 음성 인식 | 음성 입력 |
| 카메라 | **이미지에서 읽기**로 사진 촬영 |
| 사진 라이브러리 | 저장된 이미지 선택 |
| 알림 | 백그라운드 요청 결과 알려주기 |

각 권한은 해당 기능을 처음 쓸 때만 묻고, 허용하지 않아도 앱은 계속 동작해요 — 음성 입력은 키보드로, 이미지 입력은 직접 입력으로 대신할 수 있어요.

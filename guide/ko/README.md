# To-do Calendar

**할일과 일정을, 하나의 캘린더에.**

대부분의 캘린더는 약속만 담고, 대부분의 할일 앱에는 한 달이라는 감각이 없어요. To-do Calendar는 둘을 같은 그리드에 올려둡니다. 일정은 그 일이 벌어지는 날에 놓이고, 할일은 실제로 체크할 때까지 눈앞에 남아 있어요 — 시간을 정해두지 않았더라도요.

계정 없이, 인터넷 없이도 온전히 동작해요. 로그인은 데이터를 백업하고 여러 기기에서 함께 쓰고 싶을 때만 하면 됩니다.

- **하나의 캘린더, 두 종류의 일** — 일정과 할일이 나란히, 직접 만든 이벤트 종류 색으로 구분돼요
- **사라지지 않는 할일** — 시간 없는 할일과 기한이 지난 할일은 지난주로 밀려나지 않고 맨 위에 남아요
- **말로 추가하기** — AI 빠른 입력, Siri, 액션 버튼으로 일상 언어로 설명하면 이벤트가 만들어져요
- **열지 않고 확인하기** — 홈 화면·잠금화면·제어 센터를 아우르는 위젯 세트
- **쓰던 캘린더 그대로** — 구글 캘린더와 애플 캘린더를 연동해 한곳에서 보세요

## 가이드

### [1. 기본 기능](./01-basics.md)
캘린더 화면, 할일과 일정, 이벤트 추가, 반복 이벤트, 이벤트 종류와 색, 미리알림, 제일 중요한 이벤트, 완료되지 않은 할일과 완료된 할일, 일정 공유.

### [2. AI 빠른 입력](./02-ai-input.md)
말이나 글로 설명해서 이벤트를 추가하고 바꾸기. 음성·키보드·이미지, Siri, 액션 버튼, 위젯, 제어 센터, 공유 시트.

### [3. 위젯과 잠금화면](./03-widgets.md)
위젯 전체 목록과 크기, 각 위젯이 보여주는 것, 위젯에서 바로 할일 완료하기, 잠금화면 카운트다운, 제어 센터.

### [4. 외부 캘린더](./04-external-calendars.md)
구글 캘린더와 애플 캘린더 연동, 각 연동으로 할 수 있는 일, 무엇을 보이게 할지 고르기.

### [5. 개인화와 설정](./05-personalization.md)
캘린더 외관, 테마, 공휴일, 타임존, 이벤트 기본값, 그 밖의 모든 설정.

### [6. 계정과 동기화](./06-account-sync.md)
오프라인 우선 동작, 로그인하면 더해지는 것, 로그인 전에 만든 데이터 옮기기, 계정 관리.

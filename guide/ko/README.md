# To-do Calendar

**할일과 일정을, 하나의 캘린더에.**

일정은 캘린더에, 할일은 또 다른 앱에. 이번 달에 뭐가 있는지, 뭘 아직 못 했는지 알려면 늘 두 군데를 봐야 했어요. To-do Calendar는 둘을 같은 달력에 담아요. 일정은 약속한 날짜에 놓이고, 할일은 완료할 때까지 캘린더에 남아요. 시간을 정해두지 않은 할일도 사라지지 않고요.

회원가입도, 인터넷 연결도 필요 없어요. 로그인은 데이터를 백업하거나 여러 기기에서 함께 쓸 때만 하면 돼요.

- **하나의 캘린더, 두 종류의 일** — 일정과 할일이 한자리에 놓이고, 직접 만든 이벤트 종류의 색으로 구분돼요
- **사라지지 않는 할일** — 시간을 정하지 않은 할일과 기한이 지난 할일은 지난 날짜에 남겨지지 않고 캘린더 맨 위에 붙어 있어요
- **말로 추가하기** — AI 빠른 입력, Siri, 액션 버튼에 평소 쓰는 말로 설명하면 이벤트가 만들어져요
- **앱을 열지 않고 하루 확인하기** — 홈 화면, 잠금화면, 제어 센터까지 위젯이 두루 있어요
- **쓰던 캘린더 그대로** — 구글 캘린더와 애플 캘린더를 연동하면 한곳에서 다 보여요

## 가이드

### [1. 기본 기능](./01-basics.md)
캘린더 화면, 할일과 일정, 이벤트 추가, 반복 이벤트, 이벤트 종류와 색, 미리알림, 제일 중요한 이벤트, 완료되지 않은 할일과 완료된 할일, 일정 공유.

### [2. AI 빠른 입력](./02-ai-input.md)
말이나 글로 설명해서 이벤트를 추가하고 바꾸기. 음성·키보드·이미지, Siri, 액션 버튼, 위젯, 제어 센터, 공유 시트.

### [3. 위젯과 잠금화면](./03-widgets.md)
위젯 종류와 크기, 각 위젯이 보여주는 것, 위젯에서 바로 할일 완료하기, 잠금화면 카운트다운, 제어 센터.

### [4. 외부 캘린더](./04-external-calendars.md)
구글 캘린더와 애플 캘린더 연동, 각 연동으로 할 수 있는 일, 무엇을 보이게 할지 고르기.

### [5. 개인화와 설정](./05-personalization.md)
캘린더 외관, 테마, 공휴일, 타임존, 이벤트 기본값, 그 밖의 모든 설정.

### [6. 계정과 동기화](./06-account-sync.md)
오프라인 우선 동작, 로그인하면 더해지는 것, 로그인 전에 만든 데이터 옮기기, 계정 관리.

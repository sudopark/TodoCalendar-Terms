# To-do Calendar

**タスクと予定を、ひとつのカレンダーに。**

カレンダーには約束は入りますが、やらなければいけないことは入りません。タスク管理アプリはリストを見せてくれますが、それが今月のどこに来るのかはわかりません。To-do Calendar は、その両方を同じカレンダーに置きます。予定はそれが起きる日に並び、タスクはチェックするまで目の前に残ります — 時刻を決めていなくても。

アカウントもインターネットもなしで、そのまま使えます。ログインは、データをバックアップして複数の端末で使いたくなったときだけで大丈夫です。

- **ひとつのカレンダーに、予定もタスクも** — 予定とタスクが並び、自分で作ったイベントタイプの色で見分けられます
- **消えないタスク** — 時刻のないタスクと期限を過ぎたタスクは、過ぎた日付に埋もれず一番上に残ります
- **話して追加** — AIクイック入力・Siri・アクションボタンで、ふだんの言葉で説明するだけ
- **アプリを開かずに一日を確認** — ホーム画面・ロック画面・コントロールセンターにわたる充実したウィジェット
- **いま使っているカレンダーもそのまま** — Googleカレンダーと Appleカレンダーを連携して、ひとつの場所で見られます

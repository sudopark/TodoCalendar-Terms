## Appearance

<img src="https://raw.githubusercontent.com/sudopark/TodoCalendar-Terms/main/guide/images/appearance-setting.png" alt="Appearance settings" width="280">

Everything on this screen previews live as you change it, so you can see what the calendar will look like before you settle on it.

### Calendar

| Setting | What it does |
|---|---|
| Start day of the week | Which day the grid starts on |
| Accent days | Color Sundays, Saturdays and holidays — each toggled separately |
| Underline on event days | Marks days that have something on them |
| Event detail display level | How tall each row is — Minimal, Medium, or Full. Taller rows show event names instead of dots |
| Event text font size | Nudge event text up or down |
| Bold text | Heavier event names |
| Event color | Show or hide the colored bar next to each event |

### Display

- **Show holiday name** — print the holiday's name on the day, not just a color
- **Lunar calendar** — show lunar dates alongside the regular ones
- **24 hour form** — 13:00 instead of 1:00 PM
- **Show uncompleted To-do** — keep or hide the overdue to-do section at the top of the calendar

### Color theme

<img src="https://raw.githubusercontent.com/sudopark/TodoCalendar-Terms/main/guide/images/color-theme-select.png" alt="Color theme" width="280">

Follow the system, pin the app to **Light** or **Dark** regardless of what iOS is doing, or pick one of the built-in color themes. Tap a theme to apply it; the preview at the top shows how the calendar looks.

To make your own, tap **New theme** under **My themes**.

<img src="https://raw.githubusercontent.com/sudopark/TodoCalendar-Terms/main/guide/images/color-theme-edit.png" alt="Edit theme" width="280">

| Setting | What it does |
|---|---|
| Name | What the theme is called in **My themes** |
| Background | Calendar and screen background |
| Accent | Buttons and highlights |
| Style | **Filled**, **Grouped**, or **Outlined** — how event cards stand out from the background |
| Detailed colors | Text, cards, today, the selected day, holidays and weekends, and the AI button. Left on **Auto**, they're worked out from your background and accent |

To change or delete a theme later, long-press it in **My themes** and choose **Edit**.

### Widget gallery

Widget settings live in **Widget gallery** on this screen. At the top, **Widget theme** sets the background for all your widgets: they use the system theme by default, and turning off **Use system theme** lets you pick any background color — the app decides whether text should be light or dark from how bright your color is.

Below that you can customize each widget on its own. See [Customizing widgets](./03-widgets.md#customizing-widgets).

### Feel

- **Haptic feedback** — small taps as you use the app
- **Minimize animation effect** — reduces motion so the app feels calmer and quicker

## Event settings

Defaults so you're not filling in the same fields every time.

| Setting | What it does |
|---|---|
| Event type | Which event type new events get |
| Event period | Default length for a new schedule — from 0 minutes up to all day |
| Notification time | Default reminders, set separately for timed and all-day events |
| Open the Maps app | Which maps app a location opens in |

This is also where **external calendars** are connected — see [External calendars](./04-external-calendars.md).

---

## Holidays

Pick your country and its public holidays appear on the calendar. The app pre-selects the country your device is set to, and you can change it at any time.

Not every holiday is one you observe. **Hide** any of them and it stops appearing every year; hidden holidays are listed at the bottom of the same screen so you can bring one back later.

---

## Time zone

The calendar follows your device's time zone by default. If you'd rather it stay pinned to a specific one — travelling, or working with a team elsewhere — pick it from the full time zone list.
